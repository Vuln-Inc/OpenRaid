# openraid 1.0.2

Includes commit `9d4dd6d`: bulk agent controls, board coordination, and workspace storage improvements.

## Changes

- Add-count popup and batch removal with `Space` selection and `Ctrl+A`; selections persist across search filters.
- `/board`, `/export-board [PATH]`, and confirmed idle-only `/clear-board` controls. Export does not overwrite existing files; clear retains workspace files and the roster.
- New default databases use `.openraid/openraid.sqlite3`, with compatible reuse of an existing workspace-root database when the nested default is absent. Explicit and remembered database paths are preserved.
- Workspace and MCP tool coordination is advisory; positive completion votes still require a fully current board cursor.
- Initial model, roster, and pause configuration stays silent before the first objective.
- Drag-to-copy text selection and an elapsed-weighted rolling one-minute TPS display.
