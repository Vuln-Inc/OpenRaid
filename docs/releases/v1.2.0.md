Use OpenRaid from a new native desktop workspace or the familiar terminal, with the same agent runtime and saved sessions.

## What's new

- **Optional desktop app.** A separate Tauri + React executable embeds the
  existing Rust/Tokio runtime in-process. Terminal builds remain independent of
  Tauri, WebView libraries, and frontend dependencies.
- **Shared session controls.** Start, pause, resume and stop work; manage agents,
  models and reasoning variants; browse saved sessions, inspect MCP connections,
  export the board, and explicitly restore prompts/workspace snapshots.
- **Focused desktop interface.** Neutral light/dark appearances, collapsible
  project navigation, searchable selectors, a rounded prompt composer, accessible
  dialogs and Sonner notifications. Enter sends; Shift+Enter adds a newline.
- **Live agent inspection.** Event-driven updates, virtualized rosters/history
  for up to 500 agents, bounded live generation/tool/command previews and
  on-demand retained transcripts. Frontend reloads reattach to an active session.
- **One release workflow.** Each platform archive contains both the terminal
  and desktop executables, shared SDK runtime companions, documentation and
  desktop license notices. Publication requires both builds and their checks.

## Using the desktop

Launch `openraid-desktop.exe` on Windows or `openraid-desktop` on Linux/macOS
without CLI arguments, then open a workspace. The terminal remains `openraid.exe`
or `openraid`. Existing `.openraid/` databases, provider configuration and
credentials are shared; opening saved history does not start agents automatically.
Close one interface before opening the same active session in the other.

Windows requires WebView2; Linux requires WebKitGTK 4.1 and its native libraries.
macOS uses the system WebView. Source builds need Rust 1.90+ and Node.js 22.12+.
Native model transports do not require Node.js; specialized SDK-backed providers
retain their existing optional Node.js requirements.

See the [desktop guide](https://github.com/Vuln-Inc/openraid/blob/v1.2.0/docs/DESKTOP.md)
for setup, controls, safety and platform prerequisites.

## Verification

The single release workflow checks version/tag alignment, TUI dependency
isolation, Rust and frontend tests, formatting, warnings-denied Clippy, SDK
behavior, a 500-agent offline smoke, both optimized builds, combined packaging
and SHA-256 checksums. Archives are published only after all four native
platform jobs succeed; release preparation is not proof that those jobs passed.
