# openraid 1.1.1 — Idle reopening, clean rosters, and clearer agent activity

This patch fixes issues #15–#18: saved sessions open idle, remembered workspace
storage stays nested, removed agents leave the live roster promptly, and agent
inspection has a clearer OpenCode-inspired presentation.

## Fixes

- **[#15 — Reopening starts work unexpectedly](https://github.com/Vuln-Inc/openraid/issues/15):**
  reopening or switching to a saved TUI session stays idle, including unfinished
  tasks. Saved prompts, roster, votes, and checkpoints are retained without new
  provider requests or board messages. Use `/start your objective` to start work,
  `/new` for fresh history, or `openraid setup --resume` to explicitly continue
  interrupted work with its original roster and checkpoints.
- **[#16 — Root database files reappear](https://github.com/Vuln-Inc/openraid/issues/16):**
  implicit reopening corrects legacy root database paths from saved launch
  profiles and the latest-session catalog to `.openraid/openraid.sqlite3`, and
  saves the corrected launch profile. Existing root database/WAL/SHM files remain
  untouched. Data is not moved or merged automatically; use explicit `--database`
  or `--session` to open old history. Custom database paths remain supported.
- **[#17 — Removed agents stay visible](https://github.com/Vuln-Inc/openraid/issues/17):**
  the live roster follows committed membership on the next redraw. Removed
  agents finish admitted operations safely without remaining in the sidebar;
  cumulative telemetry and activity are retained. Selection follows agent
  identity when preceding rows disappear, and an inspected agent's history
  cursor resets when that agent is retired.
- **[#18 — Clearer individual-agent inspection](https://github.com/Vuln-Inc/openraid/issues/18):**
  an OpenCode-inspired transcript distinguishes response, tool, result, and
  status sections with themed surfaces. Wide terminals show session, usage,
  and activity metadata; compact layouts preserve the transcript and history
  controls. Response boundaries preserve streaming chunks, fenced payloads stay
  literal, and mouse-copy bounds match the visible transcript.

Select an agent and press **Enter** to inspect activity. Use arrows or **j/k**,
the mouse wheel, **Page Up/Down**, and **Home/End** to browse; **f** toggles live
following. **Esc/q** returns to the previous dashboard or tiled view.
