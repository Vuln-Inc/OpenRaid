More predictable session startup and a clearer view of your swarm's activity.

## Improvements

- **Idle session reopening.** Saved sessions no longer start work automatically.
  Unfinished prompts, rosters, votes, and checkpoints are preserved until you
  explicitly start or resume work. [#15](https://github.com/Vuln-Inc/openraid/issues/15)
- **Consistent workspace storage.** Automatic reopening redirects legacy root
  database paths to `.openraid/openraid.sqlite3`. Existing files remain untouched;
  explicit database/session selections and custom paths still work.
  [#16](https://github.com/Vuln-Inc/openraid/issues/16)
- **Accurate live rosters.** Removed agents leave the sidebar on the next redraw
  while admitted operations drain safely. Selection stays tied to agent identity,
  and historical activity and usage remain available.
  [#17](https://github.com/Vuln-Inc/openraid/issues/17)
- **Refined agent inspection.** An OpenCode-inspired transcript separates
  responses, tools, results, and status. Responsive metadata, clearer history
  controls, and corrected mouse-copy bounds improve readability.
  [#18](https://github.com/Vuln-Inc/openraid/issues/18)

## Using the updated controls

- `/start your objective` starts work; `/new` opens fresh history.
- `openraid setup --resume` explicitly continues interrupted work.
- Select an agent and press **Enter** to inspect it; **f** toggles live following
  and **Esc/q** returns to the dashboard.

Legacy root history is not moved or merged. Open it deliberately with
`--database openraid.sqlite3` or `--session SESSION_ID`.
