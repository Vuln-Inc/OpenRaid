Saved sessions now restore their full working history, with explicit OpenCode import and simpler Windows downloads.

## Improvements

- **Complete session restoration.** Reopening restores the objective, agent
  transcripts—including tool and command output—usage counters, roster,
  checkpoints, and pause state. Both interfaces open saved history without
  starting requests and support explicit continuation of unfinished work.
  [#27](https://github.com/Vuln-Inc/openraid/issues/27)
  · [#29](https://github.com/Vuln-Inc/openraid/issues/29)
- **OpenCode import by choice.** Detected OpenCode credentials and configuration
  require confirmation before use. The decision is remembered; import remains
  available later through `/import-opencode` or desktop Settings.
  [#28](https://github.com/Vuln-Inc/openraid/issues/28)
- **Executable-only downloads.** Release assets are limited to the two Windows
  executables and `LICENSE`, which includes embedded desktop icon attribution.
  Linux and macOS remain available through source builds and native CI checks.
- **Reliable release verification.** The startup consent regression waits for
  the dashboard's idle state before sending exit keys, avoiding a Unix readiness
  race with the consent screen. Timeouts include terminal output for diagnosis.

## Continuing saved work

Use `/resume` in the terminal or **Resume** on the desktop to continue an
unfinished task. `openraid setup --resume` also explicitly resumes it. Use
`/start your objective` for new work or `/new` for separate history. Explicitly
stopped work remains stopped.

Full activity is retained in the database's adjacent `.activity` directory.
Keep it together with the SQLite database when preserving session history.
Available legacy checkpoint history is restored where possible.

## Downloads

| Asset | Purpose |
| --- | --- |
| `openraid.exe` | Windows x86-64 terminal interface |
| `openraid-desktop.exe` | Windows x86-64 desktop interface |
| `LICENSE` | Project license and desktop icon attribution |

Download your preferred executable and `LICENSE`. Launch the desktop directly,
or run `openraid.exe setup --workspace PATH --agents 4` from a terminal. The
desktop requires WebView2. Native model transports need no Node.js; specialized
SDK providers require the sidecar from the source checkout and its dependencies.
