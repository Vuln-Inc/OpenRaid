# openraid 1.1.0 — Themes, agent inspection, and immediate stop

A more readable, inspectable terminal swarm, with immediate operator cancellation
and consistent workspace-local storage.

## Ten terminal themes

Use `/themes` or **Ctrl+X, then Y** for a searchable picker with local previews.
**Enter** applies and saves; **Esc** cancels. Select directly with `/themes nord`.

Included palettes: Openraid, Tokyo Night, Catppuccin Mocha, Nord, Dracula,
Gruvbox Dark, Rosé Pine, Solarized Dark, Catppuccin Latte, and Paper. The last two
are light themes. Setup, dashboard, menus, and mouse selection share the palette;
text/status colors and selected text meet the built-in 4.5:1 contrast checks.
See `docs/THEMES.md` for exact IDs and preference locations.

## Fixes

- **[#11 — Concurrent collaboration](https://github.com/Vuln-Inc/openraid/issues/11):**
  the coordination prompt explicitly encourages negotiating concurrent tasks
  instead of deferring to a single author.
- **[#12 — Immediate stop](https://github.com/Vuln-Inc/openraid/issues/12):**
  `/stop` immediately signals cancellation of all workers and active operations,
  before database/control-lock waits. Native process trees and PTYs are terminated;
  SDK/MCP cancellation preserves independent active requests. Queued and blocking
  file tools observe stop/caller cancellation at operation boundaries. Snapshot
  preparation is interruptible, stopped workers do not restart, and the console
  can accept fresh work afterward. Already-applied changes are not rolled back.
- **[#13 — Workspace storage](https://github.com/Vuln-Inc/openraid/issues/13):**
  default paths always use `.openraid/openraid.sqlite3`, without probing or falling
  back to a root database. Existing root files remain untouched. Explicit database
  paths and intentionally reopened sessions are preserved.
- **[#14 — Agent inspection](https://github.com/Vuln-Inc/openraid/issues/14):**
  select an agent and press **Enter** to open full-screen activity: retained streamed
  generation, tool arguments/results, and live command/PTY output. Use arrows,
  Page Up/Down, Home/End, and `f` to browse/follow; **Esc/q** restores the dashboard.
  Complete activity is temporarily disk-spooled per agent, while dashboard previews
  stay bounded. Streaming preserves split Unicode characters and agent isolation.

Pause, member retirement, completion consensus, and console close retain their
graceful safe-boundary behavior; `/stop` is the explicit immediate-cancellation action.

## Downloads

| Platform | Archive |
| --- | --- |
| Linux x86-64 | `openraid-v1.1.0-linux-x86_64.tar.gz` |
| Windows x86-64 | `openraid-v1.1.0-windows-x86_64.zip` |
| macOS Intel | `openraid-v1.1.0-darwin-x86_64.tar.gz` |
| macOS Apple Silicon | `openraid-v1.1.0-darwin-arm64.tar.gz` |

Extract the archive and run the included executable with
`setup --workspace PATH --agents 4`. Each archive includes documentation, the
license, and optional SDK runtime companions. Native transports need no Node
installation; specialized providers require Node.js 22.12+ and
`npm ci --prefix scripts` in the extracted directory.

`SHA256SUMS` accompanies the platform archives. The workflow attaches downloads
and publishes this release after all four native verification/build jobs pass.

## Verification

The combined Windows acceptance passed **298 Rust tests**, including optional
fixtures, with no failures or ignored tests, plus **25 Node tests**, formatting,
and whitespace checks. Coverage includes all ten palettes, responsive previews,
preferences, inspector navigation beyond 65,535 rows, live process Unicode,
immediate process/provider cancellation, queued blocking mutations, SQLite/control
lock contention, MCP exact-request cancellation with active sibling isolation,
and SDK reuse. Native release CI additionally runs Clippy, optimized builds,
and a 500-worker offline smoke on each platform. See `docs/VERIFICATION.md`.
